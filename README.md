# 🎀 PinkCode AI

**Your cute little AI-powered coding companion.**

PinkCode AI is a Python-based coding assistant built with Streamlit and Google's Gemini API. It helps developers generate code, debug errors, understand code line by line, and ask programming questions through a friendly, pink-themed interface.

## ✨ Features

- 🐞 **Debug My Code** — Get help identifying and fixing coding errors.
- 💻 **Generate Code** — Generate python code based on your instructions.
- 📚 **Explain Code** — Understand code step by step.
- 💬 **General Coding Assistant** — Ask programming questions and learn coding concepts.
- 🎀 **Pink-Themed UI** — A cute, beginner-friendly interface.


## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- python-dotenv

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/rivanshikaushik6/python-pinkcode-ai.git
   ```

2. Open the project folder:

   ```bash
   cd python-pinkcode-ai
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Create a `.env` file in the project folder and add your Gemini API key:

   ```text
   GEMINI_API_KEY=your_api_key_here
   ```

5. Start the application:

   ```bash
   streamlit run app.py
   ```

## 🔐 API Key Security

Keep your Gemini API key private. Never commit your `.env` file or expose your API key in public source code.
